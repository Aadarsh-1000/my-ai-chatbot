### MEMORY
Currently my AI was at a stage  where it forgot whatever the user said a message ago so I wanted to implement memory,  specifically Langchain memory as it provided a proper database to store my chats and it was also one of the best well known memories for  custom ai chatbots, However it was really challenging to implement it I tried a lot but I wasn't able to implement langchain memory successfully so I decided to use my local storage where chats would go and et stored  there and every new message the AI would go through the entire local storage chat history and that way it would have a context of what to answer for the next messages as well as well as keep track of whatever the user said in the last few messages, However this has not solved my issue of storage if there Is too many chats for the AI to go through it will start lagging and end up forgetting whatever the user said during the previous messages.

### Model Restrictions
I was experimenting with many different models but after testing long enough they started to fail their capacities overloaded and their local storage capacities for we're not as powerful as I required them to be So I ended up settling with the Groq models Specifically(llama-3.3-70b-versatile) which were free and good enough to read through my local storage without dying in the process At first I wanted to use Olama as I really loved the models that were open sourced there but later on I figured out that there were actually only local models so I spent some time switching from localhost models to the ones that are globally Deployable
